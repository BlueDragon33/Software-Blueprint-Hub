# NAV-SUPPORT-001 — Compact navigation support (candidate 2.2)

**PROPOSED_ONLY.** Constitution ACTIVE 1.3.0 remains unchanged. Owner feedback: difficult to use, not concise or focused. This is an isolated publication candidate, not an installed ChatGPT feature or a product release. Reconciles the existing #173 standard and #178 UANA guidance; does not import their Graph, reviewer or portfolio implementation.

## Proposed universal obligation

Each substantive governed-project reply or equivalent task workspace SHALL show a compact navigation support surface. Default: at most one short factual next action and exactly two main controls, **Theo Hiến pháp** and **Tạo prompt tiếp theo**. Do not repeat the report's repository, SHA, CI, status, progress or evidence links in the panel. Default to P0-first. Opening the prompt SHALL NOT send or mutate anything.

The prompt view SHALL include an editable, source-bound continuation, optional **Yêu cầu riêng** (2,000 characters), and **Sao chép** / **Thực hiện tiếp**. No mandatory wizard, radio choice or text approval for ordinary authorized tasks; protected approvals remain separate. Optional direction changes and additions must affect the generated request, and editing invalidates any prior text-only review. Preserve current goal, source, gates, authority and one next action. Revalidate exact HEAD and permissions before changes. Missing source disables execution. Copy, preview and close never send. In a supported chat host only explicit send submits a real user turn. In a Hub workspace continue opens validated internal navigation only. Unsupported host: visible Constitution link and copyable textual prompt, never a dead control. A GitHub commit cannot install persistent native chat buttons or update all ChatGPT Project settings.

Ensure keyboard/touch, light/dark, 44px target, contrast, narrow screens without horizontal overflow, and repeated replies (at least three). Separate technical quality and actual user value from independent security/human authority. A missing or misleading essential action is P0. No fake PASS, automatic approval, secret-bearing URL, new registry, app, or mandatory paid dependency.

## Effectivity

Following valid authenticated constitutional ratification and publication of the synchronized normative document, machine contract, template and policy source at one version, the obligation applies immediately to all existing/future governed projects. Unrelated product Production gates must not delay valid constitutional publication. Actual adoption, native UX and product deployment require separate evidence; no automatic bulk compliance claim. Existing gates, C33 findings and Graph NOT_CONNECTED remain unchanged. Issue #159 remains sole ledger.

## Acceptance

Technical: validate candidate contract, explicit gesture, blocked-source behavior, no authority escalation and source isolation. User value: representative owner uses the two-control default and optional prompt on three consecutive replies; measure task success, clicks and clarity against the preceding layout. A source contract test is not native host or Owner acceptance. Product runtime slice remains separate because #173's canonical NextActionView is not present in main. No production or ratification by this candidate.
